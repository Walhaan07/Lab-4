Site Safety Checker

A browser extension that embeds a button on every page the browser visits. The button shows You are on “URL”, and pressing it runs 33 tests to decide whether the site is spam and to give it a safety rating.

Part 1 — the embedded button

The extension’s content script is injected into every page (http://*/*, https://*/*). It builds a button inside a shadow root so the page’s own CSS can never break it, and labels it with the current address:

🛡 You are on “localhost:8383/index.html”

If the extension is loaded you will see the real button in the bottom right corner of this page. Otherwise, use the buttons below — this page loads the same analyser file directly.

Part 2 — test any address

Type a URL and run the 16 address-level tests, or scan this whole page with all 33 tests.

Loading the extension

  1. Chrome / Edge: open chrome://extensions, switch on Developer mode, click Load unpacked and select the extension folder of this project.
  2. Firefox: rename manifest.firefox.json to manifest.json, open about:debugging#/runtime/this-firefox, then Load Temporary Add-on… and pick that file.
  3. Reload this page — the button appears in the bottom right corner.

All tests run locally in the browser. Nothing is uploaded, no blocklist is contacted.
